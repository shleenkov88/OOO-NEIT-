# 🤝 ООО «Нейт» — Облачная касса партнёров

Современное одностраничное веб-приложение (PWA/Dashboard) для оперативного финансового учёта, распределения прибыли и контроля выплат между равноправными партнёрами в режиме реального времени.

Интерфейс оптимизирован под темную тему (Dark Mode) в стиле современных SaaS-платформ, обеспечивая удобство работы как на десктопах, так и на мобильных устройствах.

---

## ✨ Ключевые возможности

* **Учёт в реальном времени:** Интеграция с облачной базой данных Firebase Realtime Database мгновенно синхронизирует транзакции между всеми устройствами.
* **Автоматическое деление прибыли:** Система автоматически рассчитывает чистую прибыль с каждой продажи (Доход минус Себестоимость) и делит её строго в пропорции 50/50 между партнёрами (Анастасия / Наталья).
* **Контроль баланса:** Отображение грязного дохода, чистой доли и истории уже выплаченных средств для каждого участника с выводом актуального остатка к выплате.
* **Умная аналитика:** Встроенный модуль уведомлений предупреждает о кассовых разрывах (если сумма долга партнёрам превышает фактическое наличие денег в кассе) и даёт рекомендации по выплатам.
* **Интерактивный лог операций:** Полная история доходов и выплат с фиксацией времени, типа транзакции и детализацией по расходам.
* **Защита интерфейса:** Простая авторизация по пин-коду для предотвращения случайного просмотра данных сторонними лицами.

## 📐 Логика финансовых расчётов

Приложение полностью застраховано от классических ошибок JavaScript, связанных с плавающей точкой или склеиванием строк. 

1. **Доход (Продажа):**
   $$Чистая\ Прибыль = Сумма\ Продажи - Себестоимость$$
   $$Доля\ каждого\ партнёра\ (50\%) = Чистая\ Прибыль \times 0.5$$
2. **Выплата (Расход кассы):**
   Уменьшает общую кассу и увеличивает показатель «Уже выплачено» у выбранного партнёра.
3. **Текущий остаток:**
   $$Остаток\ к\ выплате = Доля\ от\ прибыли - Уже\ выплачено$$
